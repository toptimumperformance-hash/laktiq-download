# LakTiq voor Windows · downloads

Hier staan alleen de installers van **LakTiq voor Windows** (Toptimum Performance). Geen broncode, geen gegevens.

LakTiq zelf downloadt de nieuwste versie wanneer er een update is. Het controleert eerst de vingerafdruk (SHA-256) uit
`https://toptimumperformance.be/laktiq-bestanden/versie.json`.

Zonder licentie werkt LakTiq alleen om gegevens te bekijken en te exporteren. Een licentie vraag je aan via
https://toptimumperformance.be/laktiq.html.
